    What this can and cannot tell you

    • These are pattern rules, not a model that understands your program. Some findings will be false alarms, so each one shows the line and a reason so you can judge it.
    • Only files up to 150 KB are read, up to 160 per repository, and vendored or minified code is skipped. The report says when that happened.
    • Nothing is uploaded anywhere. Your browser reads the repository directly from GitHub, and the analysis runs on your device.
    • A clean score is not a security audit. It means these rules found nothing.
    Repo Doctor reads public repositories through GitHub's public endpoints. GitHub allows 60 metadata requests an hour per network.
