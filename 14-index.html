      Before an examination

      What the instrument can see.

      Four groups of deterministic pattern rules inspect architecture, security, performance and style. They do not understand the whole program. A match is not proof of a vulnerability; no matches is not proof of safety.

      Bounded coverage

      Up to 160 supported text files, 150,000 bytes each. Vendored directories, lock files, minified code, large files and unsupported formats are skipped. Source files and manifests are prioritised, then shorter paths. An incomplete file list or failed read is disclosed in the report.

      GitHub access

      Public repositories only. No account or token is requested. A real review resolves an immutable commit through three GitHub metadata requests, then reads raw files through up to six concurrent workers. Unauthenticated metadata requests are rate-limited by GitHub, usually 60 per hour per network. Requests time out after 20 seconds. Analysis has a 20-second deadline and can be cancelled.

      Data and exports

      Your browser requests public code directly from GitHub. The analysis runs here and repository code is never executed. The site does not intentionally upload repository contents or store reports on a server. GitHub receives request metadata. Exports may contain source snippets, including anything a secret-detection rule matched. Inspect them before sharing.

      Local example

      The example is original bundled demonstration code, not a real customer's repository. It uses the same rule engine and makes no GitHub requests. Applying a sample fix changes the example in this tab only.
